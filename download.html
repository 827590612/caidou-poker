安卓用户可直接下载 APK 安装包（见下方按钮），安装即用；
iPhone 用户请使用 Safari 的「添加到主屏幕」安装（iOS 不支持侧载 APK）。

🤖 安卓手机安装

  1. 用 Chrome / Edge / 自带浏览器打开上方地址。
  2. 点击浏览器弹出的「安装应用」提示，或点菜单 → 「添加到主屏幕」。
  3. 安装完成后，桌面出现「彩豆扑克」图标，点击即玩。

如果没看到安装提示：点浏览器右上角 ⋮ → 「添加到主屏幕」。

🍎 iPhone 安装

  1. 用 Safari 打开上方地址。
  2. 点底部分享按钮 ⬆️，上滑找到「添加到主屏幕」。
  3. 点右上角「添加」，桌面就会出现「彩豆扑克」图标。

iOS 必须使用 Safari；其它浏览器无法正确触发安装。

📦 安卓 APK 直接安装（无需应用商店）

  1. 点下方「📦 下载安卓 APK」按钮，把 app-release.apk 下载到手机。
  2. 打开下载文件；若提示「禁止安装未知来源应用」，按提示允许本次安装即可。
  3. 安装完成，桌面出现「彩豆扑克」图标，点击即玩（需联网，连接 Render 服务器对战）。

APK 由 GitHub Actions 自动编译并发布到 Release；每次推送代码会自动重新构建。
